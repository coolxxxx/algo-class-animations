易错：成员用 . 访问；结构体变量名不要和类型名搞混（类型 Student，变量 stu）。
进阶：完整最小示例 
struct Student {
    string name;
    int id;
    double score;
};

int main() {
    Student stu;
    stu.name = "小明";
    stu.id = 1001;
    stu.score = 92.5;
    cout << stu.name << " " << stu.score;
}
剧情：全班 3 个学生 = Student a[3]。 每个格子都是一份完整档案。下标取人，点号取字段：a[i].score。

套路：输入 n 个学生 → 循环 cin 到 a[i] 各字段 → 再循环处理/输出。
进阶：排序与函数传参 
bool cmp(Student a, Student b) {
    return a.score > b.score;  // 按分数降序
}
sort(a, a + n, cmp);

// 传结构体（拷贝）vs 传引用（可改）
void show(const Student& s) {
    cout << s.name << " " << s.score << endl;
