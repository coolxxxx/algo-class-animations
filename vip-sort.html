裁判
VIP高的优先；同级则先来先排
VS
裁判心法：先问「VIP 一样吗？」不一样 → VIP 大的 true。 一样 → 再问「到达序号更小吗？」更小 → true。两级都过不去 → false（不换）。
对照 C++ 代码 
struct Person {
    int vip;      // VIP 等级
    int arrive;   // 到达序号
    string name;
};

bool cmp(Person a, Person b) {
    // ① 先比 VIP：高的排前面
    if (a.vip != b.vip) return a.vip > b.vip;
    // ② VIP 相同：先来先排
    return a.arrive < b.arrive;
}

sort(p, p + n, cmp);
