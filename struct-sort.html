剧情：今天活动：VIP 优先；VIP 等级相同则先来先排。 sort 默认不会，需要你写「专属裁判」cmp。
点「下一步」，看裁判如何定规则
cmp(a,b) 返回 true → a 排在 b 前面
口诀：return 条件为真 = 前者该排前面。多关键字：先比 VIP，再比到达序号。 想看逐步裁判出牌加长演示，打开 vip-sort.html。
进阶：cmp 骨架 
struct Person { int vip, arrive; };
bool cmp(Person a, Person b) {
    if (a.vip != b.vip) return a.vip > b.vip; // VIP高优先
    return a.arrive < b.arrive;               // 先来先排
}
sort(p, p+n, cmp);
剧情：P1502 成绩排序：读入 n 名学生（姓名/年龄/成绩）， 按成绩从高到低输出完整成绩表。结构体打包 + 自写 cmp。
点「下一步」，跟小明排成绩表
按 score 降序，姓名年龄一起搬
套路：定义 Student → 数组读入 → cmp 按 score 降序 → sort → 循环输出。
进阶：完整 P1502 骨架 
struct Student { string name; int age, score; } a[1005];

bool cmp(Student x, Student y) {
    return x.score > y.score;  // 成绩高在前
}

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> a[i].name >> a[i].age >> a[i].score;
    sort(a+1, a+n+1, cmp);
    for (int i = 1; i <= n; i++)
        cout << a[i].name << " " << a[i].age << " " << a[i].score << endl;
}
