# C++ 算法动画课堂

GitHub Pages：https://coolxxxx.github.io/algo-class-animations/

## 学习顺序

1. **交互动画**（先看懂过程）
2. **VOX 白板片**（真落笔 + 配音字幕）
3. **代码拼装器**（概念 → 完整程序）
4. **题单 / 完整考级台**（动手做题）
